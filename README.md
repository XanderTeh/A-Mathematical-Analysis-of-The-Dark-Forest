# A Mathematical Analysis of The Dark-Forest Hypothesis
**Author: Xander Teh (University College London) (Personal Project)**

This repository contains the code, mathematical models, and visualizations for a research project analyzing Liu Cixin's *Dark Forest Hypothesis*. 

Using evolutionary game theory and agent-based Monte Carlo simulations, this project demonstrates that the Dark Forest is not a universal law of nature, but a conditional predator-prey equilibrium. Ultimately, the logic of the dark forest leads only to **mutually assured destruction**.

## Key Findings
*   **The Dark Forest:** Type I civilizations are mathematically forced into silence (prey), while Type III civilizations engage in active predation.
*   **Interstellar War:** Prolonged wars among Type III civilizations lead to mutual economic ruin, as war damage vastly outpaces their dampened exponential growth.
*   **Mutual Destruction:** The Dark Forest resolves the Fermi Paradox not through an eternal stalemate, but through total extinction. The Great Silence is a graveyard.

We frame the Dark Forest as The Prisoner's Dilemma on a cosmic scale with infinite stakes:
*   **Cooperate = Silence** (Both parties survive and grow).
*   **Defect = Attack** (A preemptive strike to eliminate a threat).
*   **The Sucker's Payoff = Extinction:** Because being attacked while silent means total annihilation, the fear of exploitation forces rational actors to defect.
*   **The Nash Equilibrium:** The only stable outcome is Mutual Defection. However, because the stakes are absolute, this equilibrium inevitably leads to mutual suicide.
